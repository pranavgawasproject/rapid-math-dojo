# Rapid Math Dojo

A daily mental addition trainer with number bonds, single-digit drills, bridging tens, two-digit addition, chained sums, and a 60-second sprint.

## Run locally

Open `index.html` in a modern browser. No build step is required. An internet connection loads Tailwind CSS, Font Awesome, and Google Fonts.

Use the on-screen number pad or keyboard digits to answer. Backspace removes a digit, Escape clears the answer, and Enter submits.

## Files

- `index.html`: the supplied application, including styles and JavaScript.
